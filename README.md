# GoDirect - 简易前端与独立下载管理器

专门为解决 **Gofile 防盗链 302 重定向、动态 WT 签名失效、破解版 IDM 无法抓取** 等痛点设计的全功能桌面级下载工具。

---

## 🌟 核心特性

1. **破解防盗链与会话鉴权**：
   * 自动在下载请求中封装 `Cookie: accountToken=...`、`Referer: https://gofile.io/` 与匹配的 `User-Agent`，彻底解决直接打开直链被 302 重定向回网页或仅下载几 KB HTML 的问题。
2. **2026 最新动态签名计算（X-Website-Token）**：
   * 针对 Gofile 全新混淆鉴权（`/js/wt.obf.js`）实施算法模拟与毫秒级 SHA-256 签名，告别油猴脚本全部报 401 / error-notPremium 的烦恼。
3. **独立多任务下载器（无需依赖外部工具）**：
   * 内置基于 HTTP Range 的多线程断点续传引擎。
   * 支持多任务并发管理、暂停、继续、取消。
   * 实时毫秒级计算瞬时下载速度、剩余时间（ETA）、动态进度条。
4. **IDM 与 cURL 一键导出**：
   * 支持一键将解析到的资源导出为携带完整 Cookie 认证的 Windows `.bat` 批处理命令，在需要时可直接调用本机外部工具。
5. **极简现代暗色 Web 界面**：
   * 提供清爽现代的控制台，单链接/批量文件树一键解析，自动打开下载文件夹。

---

## 🚀 启动与使用

### 方式一：Windows 双击一键启动（最推荐）
直接双击根目录下的 **`run.bat`** 即可：
* 程序将自动初始化后台服务，并在你的默认浏览器中打开下载管理器界面（默认地址：`http://127.0.0.1:8000`）。

### 方式二：命令行启动
```bash
python main.py
```

## ⚙️ 常见配置项说明

可在网页右上角点击“设置”进行调整：
* **默认下载路径**：文件下载完成后保存的本地路径（默认自动保存在当前工程下的 `downloads/` 目录）。
* **网络代理地址**：由于国内网络连接 Gofile 容易出现阻断，默认配置了 `http://127.0.0.1:27890`（适配常见客户端如 Clash 等）。如需修改可直接在设置弹窗中调整。
* **自定义 Gofile 账户 Token**：若拥有 Gofile Premium/VIP 账户，可填入自己的账户 Token 解除流量与单日速率限制；普通访客无需填写，程序会自动生成并持久化。
